# Financial-Dashboard 
I created an interactive finance dashboard to help executives review their KPI`s.The dashboard focuses on revenue, expenses, profitability, departmental performance, monthly trends, product offerings, and expense composition.
## Project Objective
A B2B SaaS company provided transactional data to support the development of an interactive financial dashboard for leadership. The objective of the dashboard is to provide a clear view of key financial performance indicators and support data-driven decision-making.
The dashboard focuses on revenue, expenses, profitability, departmental performance, monthly trends, product offerings, and expense composition.
